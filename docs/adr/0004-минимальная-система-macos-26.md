# 0004. Минимальная система — macOS 26

## Контекст

В проекте значилось «macOS 15+». Окно должно быть на Liquid Glass (macOS 26+) и сгодиться для портфолио. У пользователя macOS 27.

## Решение

`platforms` в `Package.swift` — macOS 26.0 (строкой, потому что `.v26` требует tools 6.2), `LSMinimumSystemVersion` — 26.0. API Liquid Glass вызываются напрямую, без `#available`.

## Почему

- Поддержка macOS 15 с запасным оформлением отвергнута: каждая стеклянная панель получила бы две версии кода, а запасная выглядела бы хуже и портила снимки для портфолио. Единственный пользователь живёт на macOS 27, выгоды от старой системы нет.
- Поднять только `#available` на местах отвергнуто по той же причине: ветвление в каждом стеклянном элементе.

## Последствия

- Программу не запустить на macOS 15 и 14, то есть не раздать другим на старых системах.
- Запись «macOS 15+» в `AGENTS.md` и README устарела и должна быть заменена.
- Вернуться назад будет дорого: стекло и сопутствующие модификаторы разойдутся по всему интерфейсу.
