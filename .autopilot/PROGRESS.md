# Транскрибатор встреч — что осталось

Последняя сборка: `.autopilot/2026-11-10-mac-app/` — оконное приложение «Транскрибатор»: Dock, список встреч со статусами и поиском, экран встречи с плеером и синхронным транскриптом, загрузка перетаскиванием с живым прогрессом, экспорт, демо-режим и скриншоты.

## Договорились — не пересматривать

- Локальная программа в строке меню, а не бот-участник созвона — пользователь согласился
- Автостарт записи при обнаружении встречи, с индикатором и отключаемой галочкой
- Результаты в `~/transcripts`: папка на встречу, Markdown + аудио
- Summary — только `claude -p` по подписке Max: «Можно совсем обойтись без ollama»
- Запись по умолчанию ручная: «Предлагаю сделать запуск не автоматическим, а чтобы я сам запускал его» (2026-10-23)
- Голосовые и диктовка не должны запускать запись: «я записываю голосовые, а также использую программу для надиктовки» — браузерам и мессенджерам нужен ещё и заголовок окна созвона
- Ориентиры по облику — от пользователя: скриншот huddly, otter.ai, tldv.io, fireflies.ai, Dribbble (`reference.md` в папке сборки); по функциям — mymeet.ai, «но только то, что мне нужно»
- Почему сделано именно так (AppKit-оболочка, `progress.json`, `user.json`, macOS 26, две библиотеки, имя бандла) — `docs/adr/`

## Известные баги

- После установки возможны два экземпляра при входе в систему (система открывает приложение заново + LaunchAgent) — защиты от второго экземпляра нет
- Закрытие окна не ставит плеер на паузу; пробел перехватывается и в диалогах «Сохранить/Открыть»
- `.mkv` и другие редкие контейнеры отклоняются как «не похож на аудио или видео»
- Реплики транскрипта отрисовываются все сразу — часовые встречи на плавность не проверены; кеш транскриптов без вытеснения
- «Последние встречи» в меню и уведомления показывают имя папки, а не название из `user.json`
- После переименования спикеров summary хранит прежние метки до повторного summary
- Упавший шаг обработки не запоминается на диске: после перезапуска ошибка без отметки шага
- При сбое повторного summary в папке готовой встречи остаётся `error.txt`
- Старая встреча без реплик и без `duration` показывает длительность 0; в экспорте без summary — «Summary нет.»
- Видео над транскриптом ограничено по высоте — в широком окне чёрные поля; у готовых встреч нет подписи «Готово»
- Демо: временные папки `transcriber-demo-*` не удаляются; положение окна общее с установленной копией; ночью до 04:00 «сегодняшние» демо-встречи уезжают во «Вчера»; у импортированных демо-встреч «Видео не найдено: /Users/demo/…»
- `--screenshots` требует доступ «Запись экрана» у запускающей программы
- С прошлой сборки: Google Meet с выключенным микрофоном держится на заголовке активной вкладки (уйти > 90 с — запись остановится); `claude` для summary может пережить выход из программы; узкая гонка при падении потока записи в момент выхода; pyannote иногда делит одного собеседника на двух
