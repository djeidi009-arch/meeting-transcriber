# Спецификация: Транскрибатор встреч

## Задача
«Я хочу свой транскрибатор встреч»: сижу на созвонах в Zoom, Google Meet, Яндекс.Телемосте, Контур.Толке и чём угодно ещё, и хочу, чтобы встреча сама записалась, превратилась в текст с разбивкой по спикерам и краткое summary — без ручной возни и без ботов в созвоне.

## Решение
Программа со значком в строке меню Mac. Она запускается при входе в систему и следит: как только приложение для созвонов (или браузер) занимает микрофон — начинает запись звука компьютера и микрофона, в меню горит красная точка с таймером. Встреча кончилась — запись останавливается сама (или в один клик), программа расшифровывает её локально на Mac, делит речь по спикерам («Я» — мой микрофон, «Спикер 1», «Спикер 2» — собеседники), просит Claude Code по подписке сделать краткое summary и кладёт в `~/transcripts` папку встречи: Markdown-файл и аудио.

## Решения по реализации

- **Две части.** Приложение на Swift (AppKit, строка меню) — интерфейс, детект встречи, запись; так macOS выдаёт разрешения на микрофон и запись экрана одному понятному приложению. Обработка — Python-программа командной строки, которую приложение вызывает на готовую папку встречи; её можно запустить и руками.
- **Запись** — ScreenCaptureKit: один поток со звуком системы (исключая собственный процесс) и микрофоном (`captureMicrophone`, macOS 15+), две дорожки в отдельные файлы. Не нужен BlackHole и перенастройка вывода звука.
- **Детект** — CoreAudio-список процессов с активным вводом (`kAudioHardwarePropertyProcessObjectList`, `kAudioProcessPropertyIsRunningInput`, bundle ID; хелперы браузеров совпадают по префиксу bundle ID) + заголовки окон из ScreenCaptureKit. Опрос раз в 2 с. Политика — чистая логика без системных вызовов, покрыта тестами.
- **Расшифровка** — `mlx-whisper` с моделью `whisper-large-v3-turbo` (быстро на Apple Silicon M4, скачивается при первой обработке, ~1.6 ГБ). Почему не whisperx: на CPU он в разы медленнее, MPS у него нет.
- **Спикеры** — `pyannote.audio` 4.x с моделью `pyannote/speaker-diarization-community-1` (уже скачана в кеше HF; токен — в `~/.cache/huggingface/token`, переменная `HF_TOKEN` не требуется) на дорожке звука компьютера; каждому сегменту Whisper назначается спикер с наибольшим перекрытием. Дорожка микрофона — всегда «Я».
- **Summary** — `claude -p` (Claude Code по подписке Max), транскрипт через stdin, без инструментов; абсолютный путь к `claude` определяется при установке и пишется в настройки (у приложения из строки меню нет PATH из nvm).
- **Окружение Python** — `uv`, Python 3.12, свой `.venv` в проекте.
- **Настройки** — `~/.config/meeting-transcriber/config.json`: папка вывода, язык, путь к `claude`, путь к python проекта, дополнительные bundle ID и шаблоны заголовков. Нет файла — значения по умолчанию.
- **Сборка приложения** — SwiftPM (хватает Command Line Tools, Xcode не нужен), упаковка в `.app` с `Info.plist` скриптом, ad-hoc подпись; установка в `~/Applications`, автозапуск — LaunchAgent.

## Вне рамок

| Требование | Почему не сейчас |
|---|---|
| Бот-участник, заходящий в созвон | пользователь выбрал локальный вариант; у Телемоста и Толка нет API для ботов |
| Имена спикеров вместо «Спикер N» | в брифе «хотя бы спикер 1, спикер 2»; имена — следующий заход |
| ollama / локальное summary | пользователь: «Можно совсем обойтись без ollama» |
| Windows / Linux | у пользователя Mac; детект и запись — macOS-API |

## Открытые места
Нет заглушек: фактов от пользователя не требуется. После установки пользователь сам выдаёт приложению доступ к микрофону и записи экрана (macOS спрашивает при первом запуске).
