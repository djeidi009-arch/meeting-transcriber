## Что должно заработать

Swift-приложение в строке меню (без иконки в Dock). Раз в 2 с смотрит, какие приложения держат микрофон и какие окна открыты; когда созвон начался — пишет звук компьютера и микрофон через ScreenCaptureKit в папку встречи, показывает 🔴 с таймером; встреча кончилась или нажали «Остановить» — отдаёт папку в очередь обработки (`<pythonPath> -m transcriber process <dir>`, Python-часть пишет таск 01 параллельно по контракту из `interfaces.md`), показывает ⏳, по готовности — уведомление. `make install` ставит всё одной командой и включает автозапуск при входе. README по-русски объясняет установку и разрешения.

## Из брифа, дословно

> «Я хочу создать свой транскрибатор встреч, который будет определять, что я нахожусь на встрече. Либо, если это проще технически, я могу добавлять встречи в Zoom, в Google Meet, в Яндекс.Телемасте, в ContourTalk, в общем, в любых известных программах для аудиоконференций.»

## Разделы спецификации

Истории 1–6, 12–14, 16–23; Решения: две части, запись, детект, сборка приложения, настройки.

## Критерии приёмки

- [ ] `cd app && swift build` собирается на Command Line Tools; `make app` даёт подписанный ad-hoc `build/MeetingTranscriber.app` с `LSUIElement` и описанием доступа к микрофону
- [ ] `MeetingDetector` покрыт `selftest`: старт через 5 с мика у Zoom/браузера; нет старта от неизвестного приложения (Wispr Flow); окно «Zoom Meeting»/«Meet –» держит встречу при выключенном мике; стоп через 90 с без признаков; после ручной остановки нет повторного старта до исчезновения признаков; автостарт выключен → нет start; `extraBundleIDs`/`extraTitlePatterns` работают
- [ ] `SystemProbe` реально возвращает bundle ID процессов с активным вводом (проверить: запустить что-то, держащее мик, напр. `ffmpeg -f avfoundation -i ":0"`, и вывести снимок отладочным флагом `--probe`)
- [ ] `Recorder` пишет `mic.caf` и `system.caf`; при отсутствии разрешения — понятная ошибка в меню и пункт «Нет доступа: открыть настройки», а не тихая пустая запись
- [ ] Папка встречи создаётся по контракту (`meta.json`, `.recording`); запись < 15 с удаляется; при запуске устаревшие `.recording` снимаются и необработанные папки ставятся в очередь
- [ ] Очередь обрабатывает папки по одной и не мешает новой записи; проверено с фейковым `pythonPath`-скриптом; ошибка обработки → уведомление с текстом
- [ ] Меню: Начать/Остановить запись, Записывать автоматически ✓ (сохраняется), Последние встречи ▸ (5, открывают `meeting.md`), Повторить summary, Открыть папку транскриптов, Выход (с корректной остановкой записи)
- [ ] `make install` / `make uninstall` ставят и снимают приложение в `~/Applications` и LaunchAgent; `config.json` получает абсолютные пути к `claude` и `.venv/bin/python`; `make check` запускает pytest и selftest
