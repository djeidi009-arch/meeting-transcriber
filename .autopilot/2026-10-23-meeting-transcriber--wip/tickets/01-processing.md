# 01 — Обработка записи: текст, спикеры, summary

**Требования:** R07, R08, R09, R11i, R12i
**Зависит от:** —
**Зона:** `transcriber/` · `tests/` · `pyproject.toml`
**Волна:** 1
**Ревью:** нет
**Модель:** сильная

## Что должно заработать

Команда `python -m transcriber process <папка встречи>` берёт две дорожки записи (микрофон и звук компьютера), расшифровывает их на русском локально (mlx-whisper, large-v3-turbo), делит звук компьютера по спикерам (pyannote community-1), убирает эхо моего голоса, склеивает в один разговор, просит у `claude -p` краткое summary и пишет `meeting.md` и `m4a`-файлы. `resummarize` переделывает только summary. Контракт папки, CLI и функций — в `interfaces.md`, следуй ему буквально: Swift-приложение пишется параллельно по тому же контракту.

## Из брифа, дословно

> «Он будет транскрибировать встречу, желательно разбивать по спикерам. Хотя бы просто спикер 1, спикер 2 и в таком духе. И выдавать краткое summary по встрече.»
> Дополнение: «Можно совсем обойтись без ollama»

## Разделы спецификации

Истории 7–11, 13 (файлы встречи), 15; Решения: расшифровка, спикеры, summary, окружение Python, настройки.

## Критерии приёмки

- [ ] `uv sync` ставит окружение на Python 3.12; `uv run pytest` зелёный без загрузки моделей
- [ ] `merge`: назначение спикеров по перекрытию, нумерация «Спикер N» по первому появлению, «Я» для микрофона, удаление эха, склейка подряд идущих реплик — покрыто тестами
- [ ] `render_markdown` даёт заголовок, длительность, `## Summary`, `## Транскрипт` с `**[чч:мм:сс] Спикер:**`; ошибка summary — текст «Summary не удалось сделать: … Меню → Повторить summary»; пустая речь — «Речь не распознана»
- [ ] `summarize` вызывает `claude -p` без инструментов с транскриптом в stdin; таймаут, ненулевой код, пустой ответ, нет бинаря → `SummaryError`; тест с фейковым скриптом-`claude`
- [ ] `process` на папке с фейковыми asr/diarize/summarize создаёт `meeting.md`, `transcript.json`, `mic.m4a`/`system.m4a`, удаляет `.caf` только после успеха; повторный вызов — no-op; отсутствующая или немая дорожка не роняет обработку; ошибка → `error.txt` и код 1
- [ ] `resummarize` перезаписывает `meeting.md` с новым summary, не вызывая asr/diarize
- [ ] Настоящий прогон: на коротком русском аудио (сгенерируй `say -v Milena` в два голоса или возьми любое) `process` реально отрабатывает с mlx-whisper и pyannote и даёт осмысленный транскрипт — результат прогона описать в отчёте
