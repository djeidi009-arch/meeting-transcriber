## Что должно заработать

Я перетаскиваю видео или аудио в окно — появляется зона «Отпустите, чтобы расшифровать», файл красиво «втягивается», встреча возникает в списке, и на её экране идёт живой прогресс по четырём этапам: «Извлечение звука → Распознавание речи → Спикеры → Summary». Когда обработка заканчивается — короткий всплеск частиц, и транскрипт проявляется каскадом. Есть кнопка «Загрузить» в тулбаре. Во время записи встречи на её экране — таймер и живая волна от громкости микрофона. Ошибка обработки видна на упавшем шаге, с кнопкой «Повторить». Анимации — главная «вау»-часть; при включённом «Уменьшении движения» они заменяются проявлением.

Приложение умеет само снять скриншоты (`--demo --screenshots <папка>`) в светлой и тёмной теме; они лежат в `docs/screenshots/`. `install.sh` запускает программу при входе с `--background`. README описывает окно.

## Критерии приёмки

- [ ] Файл, брошенный в любое место окна, создаёт встречу и открывает её; пока файл над окном — видна зона броска с живой анимацией
- [ ] Кнопка «Загрузить» в тулбаре открывает выбор аудио и видео, можно несколько файлов; несколько файлов → первая обрабатывается, остальные «В очереди»
- [ ] Не аудио и не видео → сообщение «Этот файл не похож на аудио или видео: <имя>», встреча не создаётся
- [ ] После броска проигрывается анимация загрузки (до секунды), затем экран обработки с четырьмя шагами; текущий шаг анимирован, пройденные отмечены, доля показывается, если известна
- [ ] Экран обработки читает настоящий `progress.json` (проверено на папке с подложенным файлом) и в демо проходит все этапы сам
- [ ] Ошибка: шаги останавливаются на упавшем, виден текст и «Повторить»; сбой только summary → встреча готова, с «Сделать summary»
- [ ] Переход в «Готово» на открытой встрече: всплеск частиц и каскадное появление реплик; обычное открытие готовой встречи — без задержки
- [ ] Встреча «Идёт запись»: таймер и волна, движущаяся от уровня микрофона (`Recorder.onLevel`; в демо уровень синтезируется)
- [ ] При «Уменьшении движения» анимации заменены проявлением
- [ ] `--demo --screenshots <папка>` создаёт не меньше шести PNG (`light-*`, `dark-*`: список со встречей, обработка, перетаскивание) и выходит с кодом 0; файлы лежат в `docs/screenshots/`, на них выдуманные встречи
- [ ] `install.sh` добавляет `--background` в LaunchAgent (проверено сухим прогоном `MT_HOME=<dir> MT_SKIP_LAUNCHCTL=1`); README описывает окно, загрузку, экспорт и демо-режим
- [ ] `make check` проходит
