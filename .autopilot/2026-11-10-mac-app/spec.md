# Спецификация: Mac-приложение «Транскрибатор»

## Задача

«Сейчас транскрибатор — значок в строке меню. Он работает, но окна у него нет. Хочу настоящее приложение для Mac: его можно открыть из Dock или „Программ“, оно красивое и подходит для моего портфолио продуктового дизайнера.» Встречи сейчас можно только открыть как Markdown-файл во внешней программе: их нельзя найти по тексту, переслушать с привязкой к фразе, переименовать спикеров, а при загрузке видео не видно, что происходит.

## Решение

У программы появляется обычное окно «Транскрибатор» со значком в Dock; значок в строке меню остаётся и умеет всё прежнее. В окне слева — встречи по дням со статусами и поиском, справа — выбранная встреча: плеер (звук или видео), волна, summary, транскрипт со спикерами; нажал на фразу — запись перемоталась, текущая фраза подсвечена. Файл можно перетащить в окно: красивая анимация, затем живой прогресс по четырём этапам. Встречу можно переименовать, спикеров тоже, результат — выгрузить в Markdown, DOCX, PDF или скопировать. Обработка остаётся прежней и локальной. Облик — нативный macOS 26 (Liquid Glass, боковая панель, светлая и тёмная темы) в духе присланного ориентира huddly.

## Решения по реализации

- **Оболочка — AppKit, содержимое — SwiftUI.** Существующий запуск (`main.swift`, делегат `StatusMenu`) сохраняется, окно — `NSWindow` с `NSHostingView`. Почему: строка меню, запись и `--probe` уже живут на этом запуске; переписывать их на `@main App` — риск без выгоды.
- **Общее состояние — `AppModel`.** Сейчас состояние спрятано в `StatusMenu`; окну нужен наблюдаемый слой, которым пользуются и меню, и окно.
- **Статус встречи вычисляется, а не хранится:** по файлам папки и снимку очереди. Почему: формат папки не меняется, старые встречи работают сами.
- **Прогресс — файл `progress.json`**, который пишет Python и читает Swift. Почему: не надо менять запуск процесса и сигнатуры тестовых фейков; переживает перезапуск окна.
- **Имена — отдельный `user.json`**, метки в `transcript.json` не трогаются. Почему: повторная обработка не затирает правки, переименование обратимо.
- **Минимальная система — macOS 26.** У пользователя 27; Liquid Glass без ветвлений. Прежняя «macOS 15+» в памяти проекта заменяется.
- **Библиотеки — DSWaveformImage и Pow.** Пробная сборка показала: Vortex без Xcode не собирается, Inferno собирается без шейдеров (нет компилятора Metal), Lottie и Rive проигрывают готовые иллюстрации, которых нет. Частицы, градиенты и волна-индикатор рисуются `Canvas`/`MeshGradient`.
- **Экспорт — средствами системы:** DOCX через `NSAttributedString`, PDF через CoreText. Без внешних программ.
- **Демо-режим** — отдельная временная папка с выдуманными встречами. Почему: проверять и снимать приложение, не трогая личные разговоры, микрофон и установленную копию.
- Заодно исправляется код выхода `resummarize` при сбое summary (2 вместо 1): без этого окно показало бы «Ошибка» там, где есть транскрипт.
