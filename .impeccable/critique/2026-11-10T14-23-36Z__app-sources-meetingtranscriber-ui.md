## Design Specificity Verdict
Основа авторская: волна как мотив (иконка, плеер, обработка, запись), один лаймовый акцент. Категорийное: пастельный розово-голубой градиент, конфетти из шести цветов, значок-искра у Summary.

## Priority Issues
- [P1] Нет сквозного движения: файл → волна → обработка → плеер не связаны. ImportFlight рисует карточку в центре независимо от точки броска, волна гаснет в пустоту; финал — конфетти вместо перехода волны обработки в волну плеера. Fix: одна волна проходит все состояния (matchedGeometryEffect / общий слой). /impeccable animate
- [P1] Экран обработки: пять-шесть бесконечных циклов одновременно (Aurora 30 fps, PulseWave без ограничения частоты, блик, расходящееся кольцо, variableColor, вращающаяся дуга) на минуты, пока Mac занят распознаванием; волна фальшивая (синусы). Fix: один ведущий цикл, остальное замирает; волна — настоящая форма звука файла с бегущей головкой = fraction; пауза при невидимом окне. /impeccable animate, /impeccable optimize
- [P1] Экран встречи: транскрипт — главное содержимое — ниже сгиба при окне по умолчанию; под карточкой «Спикеры» пустая колонка. Fix: спикеры — компактной полосой в шапке или липкая левая колонка, плеер липкий, транскрипт сразу под ним. /impeccable layout
- [P2] Нет anticipation, squash & stretch и overlapping action: кнопка «Слушать», значки шагов, линия между шагами (мгновенная смена цвета), полоски долей спикеров (статичны), карточка файла (равномерное сжатие). /impeccable animate
- [P2] Палитра расползлась: лайм + розовый/фиолетовый/голубой градиент + шесть цветов частиц. В тёмной теме градиент записи грязный (бордо/оливковый). /impeccable colorize
- [P2] Каскад реплик: bounce 0.25 и blur 8 на тексте, до 2 с до последней строки. Fix: без отскока, шаг 0.04, потолок 0.8 с. /impeccable animate
