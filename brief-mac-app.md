# Бриф: полноценное Mac-приложение «Транскрибатор» в красивом дизайне

## Зачем
Сейчас транскрибатор — значок в строке меню. Он работает, но окна у него нет. Хочу настоящее приложение для Mac: его можно открыть из Dock или «Программ», оно красивое и подходит для моего портфолио продуктового дизайнера. Ориентир по функциям — mymeet.ai, но только то, что мне нужно.

## Что должно остаться
- Значок в строке меню со всем, что есть сейчас: ручная и автоматическая запись встреч, уведомления, «Загрузить аудио или видео…».
- Вся обработка — текущий Python-пайплайн (`transcriber/`): mlx-whisper large-v3-turbo, pyannote, summary через `claude -p`. Локально, без ботов и облака.
- Папки встреч в `~/transcripts` и их формат (`meta.json`, `meeting.md`, `transcript.json`, `system.m4a`/`mic.m4a`). Старые встречи должны открываться в новом окне.

## Что добавить
1. Обычное окно приложения: значок в Dock, открывается из «Программ» и Spotlight, при этом значок в строке меню остаётся.
2. Список встреч (как у mymeet: по дням, название, длительность, статус: идёт запись / в очереди / расшифровывается / готово / ошибка). Поиск по названию и тексту.
3. Экран встречи: плеер (аудио или видео, если встреча из видеофайла), транскрипт со спикерами и таймкодами, синхронизация (нажал на фразу — плеер перемотался, текущая фраза подсвечивается), summary сверху. Переименовать встречу и спикеров.
4. Загрузка файла: перетаскивание видео/аудио в окно и кнопка «Загрузить». Красивая анимация загрузки, затем живой прогресс обработки по этапам: извлечение звука → распознавание речи → спикеры → summary.
5. Экспорт: Markdown (уже есть), DOCX или PDF, копировать текст.
6. Задел на будущее (не делать сейчас, но не мешать): подключение системного календаря Mac для автозаписи встреч.

## Дизайн
- Нативный современный macOS: SwiftUI, Liquid Glass (macOS 26+), боковая панель, светлая и тёмная темы.
- Анимации — главная «вау»-часть для портфолио: загрузка, обработка, появление транскрипта.
- Кандидаты (все живые, ставятся через Swift Package Manager):
  - Lottie (airbnb/lottie-spm) или Rive (rive-app/rive-ios) — иллюстрированные анимации загрузки и обработки;
  - Pow (EmergeTools/Pow) — эффекты переходов и появления;
  - Vortex (twostraws/Vortex) — частицы, например при завершении расшифровки;
  - Inferno (twostraws/Inferno) — Metal-шейдеры для фона и волны звука;
  - DSWaveformImage (dmrschmidt/DSWaveformImage) — форма звуковой волны в плеере и при записи.
- Выбрать минимальный набор, который даёт сильный результат, а не всё сразу.

## Ограничения
- macOS 27 на Apple Silicon. Xcode нет, только Command Line Tools: сборка через SwiftPM, как сейчас (`app/Package.swift`, `scripts/build_app.sh`).
- Существующие проверки (`make check`) должны продолжать проходить.
- Весь текст интерфейса — по-русски.

## Готово, когда
Приложение открывается из Dock, показывает мои реальные встречи из `~/transcripts`, загружает видео перетаскиванием с анимацией и живым прогрессом, проигрывает запись с синхронным транскриптом. Его не стыдно показать в портфолио: есть скриншоты светлой и тёмной темы.
